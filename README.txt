APPLICATION MES HEURES

Hébergement gratuit : créez un dépôt public GitHub, téléversez les quatre fichiers à sa racine, puis Settings > Pages > Deploy from a branch > main / root.
Attendez l'URL GitHub Pages (HTTPS), ouvrez-la sur téléphone et choisissez Ajouter à l'écran d'accueil / Installer.
Chaque collègue a son propre stockage local sur son appareil. Il n'y a PAS de synchronisation cloud ni de sauvegarde serveur dans cette version.
Pour une synchronisation réelle, il faudra ajouter une authentification et une base de données (par exemple Firebase ou Supabase), avec des règles de sécurité par utilisateur.
